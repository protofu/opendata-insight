전제 선언 (데이터 받기 전, 2026-10-29 작성)

질문

지금 쓰는 스마트폰의 제조사(삼성·애플 등) 비중은 나이대별로 얼마나 다른가? 2021년부터 2025년까지 바뀌었나? 같은 폰을 얼마나 오래 쓰나? (앱개발 관점: 어떤 나이대를 대상으로 하면 iOS·안드로이드 비중이 어떻게 되나)

비교군 존재 확인

  • 같은 표(DT_405001_I198)에 전체·성별·나이대(만10-19세 ~ 만70세 이상)가 같은 기준으로 있음.
  • 사용기간 표(DT_405001_I030)가 같은 조사·같은 구분으로 있음.

표 주석에서 미리 확인한 것 (kosis_notes)

  • 원자료는 소수점 둘째 자리 이상 → 반올림으로 합이 100에서 조금 어긋날 수 있음.
  • 응답 단위가 '대'(스마트폰 대수) → 사람 수가 아니라 폰 대수 기준일 수 있음. 받은 뒤 응답수로 확인.
  • 사용기간 표의 구간이 해마다 다르게 나뉠 수 있음(1년 단위 / 6개월 단위) → 받은 뒤 어떤 해에 어떤 구간이 있는지 확인.

데이터

  • KOSIS DT_405001_I198 「스마트폰 제조사별 점유율」, DT_405001_I030 「스마트폰 사용기간」 (방송통신위원회 「방송매체이용행태조사」), 2021~2025

전제

  1. '점유율'은 조사 응답자가 쓰는 폰 기준이다. 판매량이 아니다.
  2. 제조사 = 운영체제로 바로 읽는다(애플 = iOS, 그 외 = 안드로이드)는 근사다 — 글에서 근사임을 밝힌다.
  3. 사용기간은 '지금 폰을 산 뒤 지난 기간'일 가능성이 높다(교체 주기와 다름) → 문항 정의를 확인하고 못 하면 한계에.
  4. 특정 제조사를 홍보하거나 평가하지 않는다.

완료 기준

  • 제조사 비율 합 ≈ 100 확인
  • 최신 값을 보도자료와 대조(가능하면)
  • 차트 1~2개, 글 1편, 한계
