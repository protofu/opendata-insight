질문

임금근로자 중 비정규직 비율은 나이대별로 얼마나 다른가? 20대·60세 이상은 어떻게 바뀌었나?

비교군 존재 확인

  • 같은 표(DT_1DE7006S)에 나이대별 임금근로자·정규직·비정규직(한시적·기간제·시간제·비전형)이 같은 기준으로 있음.

표 주석에서 미리 확인한 것 (kosis_notes)

  • 2019년에 기간제 근로자가 추가로 포착됨 → 한시적·비정규직·정규직은 2018년 이전과 2019년 이후를 나눠서만 비교 가능. 2018 → 2019 변화는 말하지 않는다.
  • 비정규직 정의는 노사정위원회 합의(2002년 7월).
  • 10대(특히 성별 10대)는 상대표준오차가 큼 → 10대는 쓰지 않거나 주의.
  • 매년 8월 조사(기간 구분 월, YYYY08).

데이터

  • KOSIS DT_1DE7006S 「성/연령별 근로형태(비정규직)별 취업자」 (국가데이터처 「경제활동인구조사 근로형태별 부가조사」), 2003~2025년 8월

전제

  1. 비정규직 비율 = 비정규직 ÷ 임금근로자.
  2. 비정규직 하위 유형(한시적·시간제·비전형)은 겹친다(한 사람이 둘 이상에 해당 가능) → 하위 합 ≠ 비정규직.
  3. 원인과 좋고 나쁨은 판단하지 않는다(시간제를 원해서 고른 경우도 있음).

완료 기준

  • 정규직 + 비정규직 = 임금근로자 확인
